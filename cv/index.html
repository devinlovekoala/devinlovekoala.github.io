Projects

  • 2025.03 - Present
    Drawsee (昭析) — Multimodal AI Dialogue & Circuit-Analysis Platform
    Founder & Backend Lead (Personal Project). Sole backend owner from the first commit — 330+ commits, over 90% of the repository. Spring Boot 3.4 + LangChain4j + Qdrant + MySQL + Redis + RabbitMQ + MinIO.
    • Circuit-Design Agent Closed-Loop Workflow — Plan → Generate → Structured Verification → Repair → Archive, using a deterministic simulator (not model self-evaluation) for functional-level verification, with a stateless-pure-function termination policy that can be tested and evolved independently.
    • Drawsee Self-Improvement System — fully automated loop covering issue discovery → candidate generation → canary validation → auto-promotion/rollback, judged with two-proportion sequential significance testing; fixed three statistical/attribution defects in the prior implementation.
    • In-House Agent Evaluation Harness (TestLab) — general-purpose Agent evaluation infrastructure with environment isolation, credential management, and a deterministic-replay engine for step-by-step, fingerprint-compared replay of any Agent decision.
    • Backend Foundation Architecture — unified multi-model orchestration (Qwen/DeepSeek), Qdrant RAG pipeline, RabbitMQ async tasks, Redis Stream + SSE streaming, MinIO, Flyway migrations, Sa-Token auth, multi-environment CI/CD.
  • 2025.01 - Present
    FORGE: Verifier as Teacher
    In progress — targeting IJCAI-27 / AAAI-28. Working with my advisor on a post-training method incubated from Drawsee's circuit-design agent scenario.
    • In engineering-verification environments supporting counterfactual queries (EDA design, GPU kernel optimization), a deterministic verifier acts as a counterfactual teacher, constructing Verified Counterfactual Pairs (VCP) for model-proposed design edits.
    • Distills verifier-guided search and effect knowledge into a small model's weights, so the student achieves higher task success and better effect-prediction calibration without extensive, high-latency tool calls at deployment.
    • Currently in mid-stage experimental validation.
